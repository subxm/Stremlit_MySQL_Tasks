# 🧾 Inventory & Billing Management App

A shop inventory and billing system built using **Streamlit** and **MySQL**.

---
## Preview
[https://inventory-billling-app.streamlit.app/]

## 🚀 Features
- Add products (name, price, stock)
- Auto stock update after billing
- Generate bills
- Store bill data in database
- Daily sales summary
- Download bill as CSV

---

## 🧰 Tech Stack
- Streamlit
- MySQL
- Python

---

## ▶️ How to Run
```bash
pip install streamlit mysql-connector-python pandas
streamlit run app.py
streamlit run billing.py
```
