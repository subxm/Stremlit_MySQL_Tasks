# 🎓 Student Attendance & Marks Portal (Streamlit + MySQL)

A full-stack web application built using **Streamlit** and **MySQL** to manage student details, attendance, and subject-wise marks with reports and analytics.

---

## Preview

[https://student-attendance-marks10.streamlit.app/]

## 🚀 Features

- 🔐 Login system (session-based)
- 👨‍🎓 Add student details (Roll No, Name, Class)
- 📅 Mark daily attendance (Present / Absent)
- 📘 Add subject-wise marks
- 📊 View attendance history
- 📈 Calculate attendance percentage
- ✅ Automatic Pass / Fail status
- 🗃 MySQL database integration
- ☁️ Cloud-deployable (Streamlit Cloud + Railway MySQL)

---

## 🛠 Tech Stack

- **Frontend:** Streamlit  
- **Backend:** Python  
- **Database:** MySQL  
- **Libraries:**  
  - streamlit  
  - pandas  
  - mysql-connector-python
