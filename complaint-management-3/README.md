# 📝 Online Complaint Management System

An online complaint registration and tracking system built using **Streamlit** and **MySQL**.  
Users can submit complaints, and admins can track and update complaint statuses.

---

## 🚀 Features

### 👤 User Module
- Submit a complaint with:
  - Name
  - Email
  - Category
  - Description
- Auto-generated Complaint ID
- Input validation

### 🛠️ Admin Module
- View all complaints
- Update complaint status:
  - Open
  - In Progress
  - Closed
- Search complaints by Complaint ID
- Clean UI with expandable complaint details

---

## 🧰 Tech Stack

- **Frontend & Backend**: Streamlit (Python)
- **Database**: MySQL
- **Connector**: mysql-connector-python
- **Version Control**: Git & GitHub
